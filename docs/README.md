# Projeto Zenith — Cadastro de Usuários (Desafio U3)

Sistema de cadastro desenvolvido na plataforma **Wix** focado em agilidade, interface funcional e fluxo de dados eficiente.

## 🚀 Justificativa Técnica
* **Agilidade (Drag & Drop):** Layout moderno criado rapidamente sem código manual.
* **Foco em UX:** Interface intuitiva e jornada de cadastro simplificada.
* **Banco Integrado:** Armazenamento automático via Wix CMS, sem complicação externa.

## 📊 Análise Crítica
* **Vantagens:** Prototipagem rápida para MVPs, curva de aprendizado nula e facilidade de colaboração.
* **Limitações:** Dependência da plataforma (Vendor Lock-in), customizações complexas exigem código (Velo JS) e menor controle sobre segurança avançada.
